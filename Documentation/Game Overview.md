# Game Overview

First person adventure game.

# Features
- 3D environments
- Player movement in 3D (forward, backwards, strafe left and right, mouse look, turning, no jump)
- Crouch
- Feature 3
- Player can pick up and put down objects
- Audio / Sound design: ambience, music, voice over, sound effects
- Physics objects: player can bump objects that then move realistically, player can toss objects that fall and roll realistically
- Animated doors / closeable doots
- Vhs tape that can be inserted into vcr and play on TV
- Audio tapes that can be inserted into tape player
- Interactive objects highlight when player looks at them in interact range
- Highlighted interactive objects have text labels (state based)
- Object inspection mode: hold right click while object is picked up to rotate it around
- Interacting with objects can trigger voice over
- Journal: interacting with certain objects casuses notes to be stored in a "journal" UI screen 
- Readable objects: when interacted with, they appear in a static view front and center of screen. They cannot be rotated like other objects. They do support multiple pages by clicking left and right arrow UI buttons. There's also a close button.
- Environmental storytelling
- Locks and keys
    - Password
- Interactive switches and buttons that trigger various things (e.g. lights)
- Narrative plot / story
- Map
- Inventory
